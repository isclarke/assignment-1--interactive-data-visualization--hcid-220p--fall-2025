---

## ❖・Introduction・❖

In this assignment, you will plot the dates and times from a CSV file onto a single x-axis. The scaffold required to carry out this assignment is included here; you needn’t add any files.

---

## ❖・Requirements・❖

* The width of your container, marked with ID `data-csv-container` in `index.html`, must be 1200 pixels.
* The entire visualization, including x-axis and content, must fit in this container.
* Use only the content in `data/data.csv`, which contains date ranges for about five weeks.
* The beginning of each week must be Sunday. Thus, indicate this to the user in your visualization.
* Mark a dot or a perpendicular line to the x-axis for every day of the week.
* Every date between the first date in `data.csv` and the last date one must be included in your visualization, whether it appears in `data.csv` or not. To keep the data tidy in the visualization, omit the year.
* Highlight in your visualization every date in `data.csv` that contains a timed event.
* Distinguish timed events from each other based on the amount of events that occur in a single day.
* No libraries may be used; only `d3.js` is allowed.
